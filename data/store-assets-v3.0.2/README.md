每组四张竖向画布，符合 3–10 张的数量要求。由 [素材生成工具](../../tools/prepare_store_assets.ps1) 等比例放入背景画布，保留完整界面，不裁切、拉伸或增添控件；图片大小逐张检查不超过 5 MiB，图标不超过 3 MiB。规格来源见 [发布清单](../../docs/APPGALLERY_RELEASE.md)。

原图在 [v3.0.2 验证](../v3.0.2-validation/README.md) 的 raw 目录。MatePad 原生方向下 ROTATION_0 是横屏、ROTATION_90 是竖屏，命名依据实际宽高，而非假设设备自然方向。

**phone 目录是手机规格宣传画布，截图来源仍为真实平板。它不代表本轮做过手机真机验收。** 正式邀请测试阶段应在目标手机复核布局与后台策略，按平台要求替换成手机实拍；旧 v2 手机模拟器图没有混入本组素材。

目前仅准备本地文件和 GitHub 开源附件，尚未上传 AGC 或提交审核。图标前景沿用自有波形，背景为不透明纯色 #F58720。
