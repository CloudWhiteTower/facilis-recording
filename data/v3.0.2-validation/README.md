## 边界和历史

本轮后台验收范围为 FLAC、M4A 切到桌面后持续录音，十分钟锁屏实录为 WAV；不把它写成全部设备、全部格式的锁屏验证。真实来电中断、权限录制中撤回、声学质量、帧时间与功耗仍需针对性测试，Host 中的系统状态注入不能替代这些实验。

新版 PCM 分享缓存不等于资料库，系统可回收缓存；24 小时指应用不主动删除近期完整副本。原始录音和系统文件选择器导出的外部文件不参加副本清理。
