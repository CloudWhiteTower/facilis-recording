# Facilis Recording 3.0.2

v3.0.2 / 3000002 补齐应用市场准备功能并修复面板与录音状态问题。最低兼容与目标 SDK 保持 API 24，包含 ARM64 和 x86_64 原生库，包名及录音目录保持不变。

## 更新内容

- 修复资料库和播放器“转换格式”的退出残影、滚动位置复用及动作分支交叉；约束面板边界。
- 保存到文件与分享等待应用面板退出后再打开系统界面，避免两个面板叠层。
- PCM 工作副本采用专用缓存，处理容量、过期、短读写和失败清理。新副本生成后 24 小时内应用不主动删除，正在分享的副本额外保护，超过 7 天的副本在启动或导出时清理；系统仍可回收缓存。
- 设置提供副本清理、离线隐私说明与麦克风权限设置；旧 exports 只在明确确认后清理，原始录音不受影响。
- 同步 M4A 系统暂停、停止及异常状态，冻结计时并尝试保存已录部分，隔离旧实例回调。
- 分层图标背景改为不透明纯色，准备当前界面的规范尺寸截图。
