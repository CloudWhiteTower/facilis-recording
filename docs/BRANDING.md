# 品牌与图标

## 名称

`facilis` 是拉丁语第三变格形容词，基本义为“容易的、简便的、易于使用的”。它的阳性/阴性主格单数形式是 `facilis`，中性主格单数是 `facile`。

`Recording` 是英语名词，因此 `Facilis Recording` 不是完整的拉丁语短语，而是“拉丁品牌词 + 英文功能词”的混合命名。作为产品名读写自然，仓库 URL 使用 `facilis-recording`。若追求纯拉丁语，可以另选描述“声音/录音”的拉丁词，但会降低普通用户的可识别性，所以本项目保留当前命名。

## 图标

- 主题：橙色渐变背景 + 暖白色麦克风/波形。
- 规格：1024×1024 PNG，背景与前景分层。
- 背景：不透明，上浅下深，适配鸿蒙系统遮罩。
- 前景：透明画布，主体居中并保留安全边距。
- 源文件：`tools/generate_icon.ps1` 可重复生成工程内两套分层资源与预览图。

最初的图形方向经过视觉草案探索，最终工程资源改为确定性绘制，避免细碎像素影响小尺寸清晰度。
