# 审核操作说明与提交前验收

编写日期：2026-10-09。当前工程：Facilis Recording v3.0.2 / 3000002，HarmonyOS API 24，手机和平板。首次正式提交时按最终软件包同步填写版本、Bundle Name 和 App ID；目前开发者实名、公开邮箱、App ID 与发布签名仍待本人注册后配置。

## 可填写给审核人员的说明

本应用为离线录音、播放和文件管理工具，无注册登录，无服务器及测试账号。无需购买、兑换或连接外部设备即可使用核心功能。仅在用户主动开始录音时申请麦克风权限；拒绝后仍能浏览设置及已有录音。录音、格式转换和资料库操作在本地完成，文件保存和分享由用户主动选择系统目标。

测试建议使用普通说话或环境声音，不要使用真实私人内容。商店托管启用后，初次运行按系统隐私提示操作；当前本地侧加载包不以托管首启弹窗为验收依据。开始录音时允许麦克风权限，可在“设置 > 隐私说明”离线阅读数据处理规则。

| 功能 | 操作 | 预期结果 |
| --- | --- | --- |
| 录音与播放 | 选择 WAV、M4A、FLAC，分别录制 10–20 秒；暂停、继续、保存，然后打开播放 | 波形随声音变化；暂停时计时停止；保存后可播放及拖动进度 |
| 格式配置 | WAV 选择 44.1/48 kHz、16/24-bit；M4A 选择 128/256 kbps；FLAC 选择 16-bit | 保存文件与选择的参数一致；三种格式均为单声道 |
| 格式转换 | 对录音选择不同目标格式，完成后播放副本；再测试运行中取消 | 显示进度；完成输出可播放；原件保留；取消无残缺录音导入资料库 |
| 操作浮层 | 打开“转换格式”，返回操作菜单，再调用分享/保存/删除；反复关闭与重开并切换方向 | 浮层内容无交叉残留；系统面板和确认弹框在操作浮层退出后显示；运行中不能误触重复操作 |
| 管理与删除 | 搜索、重命名、多选移入最近删除；批量恢复或永久删除 | 列表和实际文件一致；恢复后可播放；永久删除的项目从最近删除消失 |
| 保存与分享 | 保存到系统文件选择器指定位置，或打开系统分享面板 | 外部副本与原件独立；取消保存不改变原件 |
| 隐私与权限 | 查看“设置 > 隐私说明”；拒绝录音权限后主动进入“麦克风权限”重新授权 | 隐私内容断网可读；拒绝仍可使用已有录音；重新授权后可录音，刚拒绝授权不会连续弹框 |
| PCM 副本清理 | WAV 导出 PCM 后进入“设置 > 清理分享副本”，检查统计并取消或确认；结合受控旧副本检查过期和失败处理 | 新完整副本 24 小时内受应用清理保护；旧版本副本仅手动确认删除；检查/删除失败与保留数准确，原录音、最近删除、外部副本不受影响 |
| 显示与切换 | 左右滑动切换主页面；浅色/深色；手机/平板横竖屏 | 内容无裁切，操作可达；录音期间受保护的切换按界面提示执行 |

WAV 完成长时间锁屏验收；FLAC/M4A 此处是切到桌面的短后台场景，不能描述为三种格式均完成锁屏。新截图已排入手机/平板各 4 张规范画布，来源为真实平板；手机规格不代表手机硬件验收。详见 [验证记录](../data/store-readiness-validation/README.md)及 [素材来源](../data/store-assets-v3.0.2/README.md)。
