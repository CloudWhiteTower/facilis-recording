# 应用市场提交准备审查

日期：2026-10-09。当前工程 v3.0.2 / 3000002，个人开发者，首发包含中国大陆。保持 API 24 和现有应用身份；本轮处理工程与素材，尚未注册或提交 AGC。

## 本轮处理

| 项目 | 处理与验证 |
| --- | --- |
| 转换与其他浮层 | 移除互斥分支的退出残影，重置滚动位置并限制内容边界；系统分享/文件选择器等待 Sheet 完成退出后再打开。资料库转换、重命名、播放器转换/保存及隐私横竖屏真机检查通过 |
| PCM 分享副本 | 新副本放入专用缓存，保护 24 小时内和正在分享的完整副本；超过 7 天在启动或导出时清理。最多 32 个文件/2 GiB，近期副本占满时准确报错。旧 exports 只手动确认清理，取消分享不立即删除完整副本 |
| 清理入口 | 设置可查看可清理数量和大小，明确确认后清理；准确反馈保护和检查/删除失败。只操作可识别工作副本，不影响资料库、最近删除或外部文件；四项隔离真机缓存用例和 Host 失败注入通过 |
| 离线隐私 | 设置可离线阅读隐私说明，包含权限、后台、本地处理、保存分享、PCM 副本与删除规则。正式发布者、邮箱和生效日期待注册后补齐，托管首启弹窗不重复实现 |
| 麦克风设置 | 用户主动进入设置才追加权限设置引导；刚拒绝录音授权不会连续弹窗。12 项 Host 检查覆盖拒绝、永久拒绝、设置返回及异常，真机撤回/恢复仍列为正式邀请测试项 |
| M4A 系统状态 | 监听 AVRecorder stateChange，系统暂停/停止时冻结时长并尝试保存，避免二次 stop 和旧实例回调；新增六项 Host 用例 |
| 图标 | 最终 APP 的两层 PNG 均为 1024×1024，背景为纯色 RGB #F58720 / alpha 255，字节与源码一致；Release、ohosTest 与增量构建校验通过 |
| 截图 | 当前真实 MatePad 横竖屏已采集；四张规范画布/设备规格已准备。手机规格画布来源为平板，不代替手机真机验收 |
| 后台与锁屏 | 60/60；FLAC 47.800 秒、M4A 47.893 秒桌面后台实录、暂停继续、保存和播放通过。WAV 600 秒墙钟锁屏，实际文件 599.900 秒，120/120 次采样确认熄屏，完整解码通过 |

应用不主动删除近期缓存，不代表系统永不回收缓存。永久删除原件与清理工作副本是不同操作，导出到系统文件选择器的外部文件也不参加清理。
