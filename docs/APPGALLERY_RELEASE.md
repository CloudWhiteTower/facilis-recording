# AppGallery 发布清单

文档与官网核验日期：2026-10-09。当前工程为 Facilis Recording v3.0.2 / 3000002，发布主体为个人开发者，首发包含中国大陆。官网发布、资质、备案、隐私及素材说明已核对；不一致的版权要求单独列为 AGC 确认项。

## 结论

当前处于 v3.0.2 提交准备阶段。PCM 分享副本清理、离线隐私入口、麦克风权限设置，以及格式转换和其他操作浮层的叠层修复已实现；Host 检查 227/227、真实功能/UI 88/88、后台锁屏套件 60/60 通过。MatePad Air 完成 FLAC、M4A 切到桌面后的短录音，以及 WAV 600 秒墙钟锁屏实录；不能由此宣称三种格式都已完成锁屏验证。

商店画布素材已生成，但手机规格素材来源为真实平板截图，仍需在邀请测试阶段用真实手机替换或核验。最终 Release 和测试模块已构建成功，APP 内两层图标均为 1024×1024，背景为纯色 `#F58720`、完全不透明，字节与源码一致。最终包 65/65 项 UI/长文件播放复验通过，失败和错误均为 0，包含十分钟 WAV 的开头、中部和末尾播放。

此前一次长文件播放的位置断言失败，原断言保留后增加诊断重跑 58/58 通过，最终 65 项套件中再次通过；该次失败原因仍未确定，不宣称已经定位业务根因。正式身份与发布签名须在本人注册后配置，尚未提交 AppGallery Connect。

v3.0.1 的 GitHub 源码和未签名 Release 附件是历史交付，见[附件说明](../release/v3.0.1/README.md)，不包含本轮修复。当前交付入口为 [v3.0.2 附件说明](../release/v3.0.2/README.md)；GitHub 附件不能直接替代正式发布签名包。

本轮修复和未完成项目见 [提交准备审查](STORE_READINESS.md)。旧文档中“中国大陆必须先办理 APP 备案和软著”的笼统表述已更正：单机 APP 有无需备案的申报路径；软著是否需要提交须处理官方两处说明的差异。

## 官方发布流程

1. 本人在[华为开发者联盟](https://developer.huawei.com/consumer/cn/)注册并完成个人实名认证，准备身份证件、有效手机号/邮箱及平台要求的核验信息；下载个人开发者承诺函并按模板签署。
2. 确认应用名称、最终 Bundle Name、分类、默认语言、Phone/Tablet 支持范围。
3. 生成 Release 类型 `.app`，按当前工具链与 AGC 要求配置发布签名；本项目保持 API 24，GitHub 未签名附件不能替代此步骤。
4. 上传 APP，并确保包名、版本、设备范围与 AGC 中注册的信息一致。
5. 配置本地化信息：名称、图标、一句话简介、详细介绍、版本特性、截图/视频。
6. 完成内容分级、隐私标签、版权字段和审核联系人；在核准（备案）信息中如实申报单机 APP。若版权字段阻止提交，先向华为官方提单确认，不根据相互冲突的旧文档提前购买代理服务。
7. 在“服务 > 协议服务”新建隐私政策，建议使用标准化隐私托管，补全发布者姓名、联系邮箱、信息用途、权限、存储和删除规则。应用已有“设置 > 隐私说明”离线入口，提交时与正式政策核对一致；托管系统首次弹窗不得再重复自建。
8. 先发布邀请测试，验证正式身份包的隐私、安装升级、手机/平板与后台录音，完成[审核验收](STORE_REVIEW_GUIDE.md)及漏洞/兼容性/稳定性/性能检查，再由发布者确认内容分级、分发地区和上架时间并提交审核。

## 单机 APP 与版权的适用范围

[华为核准（备案）信息说明](https://developer.huawei.com/consumer/cn/doc/app/50130)（页面更新 2026-06-25）允许无需核准（备案）的应用选择单机 APP，定义依据是未通过公共互联网提供互联网信息服务。当前本应用的采集、播放、转换和索引均在设备内进行，没有网络权限、账号、广告或云端功能，适合按此路径申报。系统分享是用户选择其他应用的操作，应如实说明，不等于本应用经营云服务。无需仅为上架购买服务器或域名；最终仍由平台核验。未来新增网络服务时重新评估。工信部[备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)的适用对象为境内从事互联网信息服务的 APP 主办者。

[应用资质总则](https://developer.huawei.com/consumer/cn/doc/app/80301)（更新 2026-09-02）称 APP 软件著作权证书非必选，个人开发者需提供承诺函；但[配置版权信息](https://developer.huawei.com/consumer/cn/doc/doccenter-submission/agc-help-release-app-copyright-0000002278981450)（更新 2026-06-25）的表格仍称包含中国大陆的手机应用需应用版权或代理证书。这两处不能直接合并成“软著必须办理”或“任何版权材料都不用”。创建实际应用后查看可填写项，保留官方工单答复；若确需证书，再选择官方认可的登记或电子版权途径。

MIT 是许可方式，不是登记证书，也不证明所有图形/名称无第三方权利冲突。项目保留了自有图标、代码许可和系统运行库声明；首次发布前由发布者确认名称和素材权属。

## 本应用的隐私填写要点

- 麦克风用途：仅在用户主动开始录音时采集声音并生成本地音频文件。
- 数据保存：录音位于应用私有目录；关闭了应用备份恢复，不会由本应用主动上传。
- 分享：仅在用户主动选择分享时调用系统分享面板，由用户决定目标应用或设备。
- 保存与转换：系统文件选择器只在用户操作时保存副本；格式转换在本地完成并保留原件。删除应用内录音不会自动清理外部副本。
- 删除：支持最近删除、恢复和永久删除。
- 新 PCM 分享副本位于应用私有缓存。应用不会主动删除生成 24 小时内的完整副本，以免接收方未读完；之后可在“设置 > 清理分享副本”确认清理。超过 7 天的副本在下次启动或导出时清理；系统也可能回收缓存。旧版本 `exports` 中可识别的 PCM 副本仅通过手动确认清理。
- 永久删除资料库原件与清理分享副本是独立操作；清理不会触及资料库、最近删除或保存到设备的外部文件。当前正在使用或处于保留期的副本保留，无法检查或删除的文件准确提示，不宣称所有副本同时删除。
- 应用内隐私说明可离线阅读。麦克风被拒绝后，可通过“设置 > 麦克风权限”主动重新授权；刚拒绝一次授权时不会立即追加第二个权限弹框。
- 账号、广告、分析、定位、通讯录：当前版本均不使用。
- AGC 中“设备权限调用”的麦克风说明必须与软件包实际权限一致，否则无法提交审核。

## 素材检查

- 软件包分层图标：已验证最终 APP 前景/背景各为 1024×1024 PNG；背景纯色 `#F58720`、alpha 全部为 255，两层字节均与源码一致。构建插件在标准打包前恢复原始 PNG，打包后只读验证；未修改 SDK 或签名材料。
- [市场素材规范](https://developer.huawei.com/consumer/cn/doc/doccenter-operations/agc-help-app-visual-asset-spec-0000002277607976)（更新 2026-09-08）：手机/平板图标各按设备配置一张，216×216 或 1024×1024；PNG 不超过 3MB，WEBP 不超过 100KB。
- 手机介绍截图 3–10 张：竖版 1080×1920 或横版 1920×1080；平板 3–10 张：竖版 1280×1920 或横版 1920×1280。同设备方向一致；PNG/JPG/JPEG 不超过 5MB，WEBP 不超过 200KB，不使用动图。
- 当前 MatePad 原始截图为 1840×2800 / 2800×1840，不能直接当作合规尺寸素材；应完整保留界面后排入对应画布，避免拉伸或裁掉控件。
- 本轮已生成 [v3.0.2 商店素材](../data/store-assets-v3.0.2/README.md)：每个规格 4 张，手机 1080×1920、平板 1280×1920。两组均来自真实平板界面，手机画布仅用于素材准备，不证明手机硬件已验收；邀请测试阶段替换或核验。
- 应用市场只使用本项目界面截图；本地第三方参考图片不随发行版分发。
- 当前商店文案草稿见 [STORE_LISTING_ZH.md](STORE_LISTING_ZH.md)。

## 正式签名前的安全要求

- 先在 AGC 创建 HarmonyOS 应用并获得 App ID，确认最终 Bundle Name。现有 `com.example.harmonyrecorder` 尚未登记；若改变应用身份，需同时核对后台 WantAgent 等引用，并规划测试应用录音的导出/迁移，不通过卸载来解决签名冲突。
- 沿用手动发布签名流程：DevEco Studio 生成密钥库 `.p12` 与证书请求 `.csr`；在本人 AGC 账号申请发布证书 `.cer` 与发布 Profile `.p7b`；本机配置后构建正式 Release `.app`，再上传 AGC。现有调试证书和 GitHub 未签名包均不能替代这一流程。参见[官方发布与签名指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app)。
- `.p12`、`.cer`、`.p7b`、`.csr`、私钥和密码只存放在开发者控制的安全位置。
- 不把签名配置、本机绝对路径、调试日志、录音样本或源码上传到 AGC 的软件包上传区。
- 公开工程不包含本机调试签名材料；开发者需在自己的环境配置签名，上传前核对归档和包内容。
- 如果更换正式签名证书，应先确认后续升级路径；同一应用的更新必须保持签名体系一致。
