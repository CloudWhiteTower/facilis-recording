# 应用市场文案草稿

## 应用名称

Facilis Recording

## 一句话简介

简洁、离线优先的鸿蒙原生录音工具

## 分类建议

工具

## 应用介绍

Facilis Recording 是一款专注于本地录音的 HarmonyOS 原生应用。你可以按用途选择 WAV 或 M4A 质量，录制时实时查看波形、时长和文件大小，并在录音库中完成搜索、播放、重命名、分享与删除。

应用不要求登录，不包含广告，也不会主动上传录音。浅色与深色外观均采用简洁的橙色主题，并针对手机和平板布局进行适配。

## 核心功能

- WAV 44.1/48 kHz、16/24-bit 录音
- M4A 44.1/48 kHz、128/256 kbps 录音
- 实时波形、分贝刻度、计时和大小显示
- 暂停、继续、保存或放弃录音
- 本地搜索、多选、重命名、分享与最近删除
- 播放、暂停和进度拖动
- 浅色/深色主题与手机/平板适配

## 隐私摘要

仅在用户主动录音时申请并使用麦克风。录音默认保存在应用私有目录，不要求账号，不包含广告或第三方运行时 SDK，也不由应用主动上传音频。
